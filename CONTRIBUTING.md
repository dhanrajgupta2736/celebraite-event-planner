# Contributing to CelebrAIte PRO

Thank you for your interest in contributing to CelebrAIte PRO!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhanrajgupta2736/celebraite-event-planner.git
   cd celebraite-event-planner
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Run unit & integration tests:**
   ```bash
   npm test
   ```

5. **Run linter:**
   ```bash
   npm run lint
   ```

6. **Verify production build:**
   ```bash
   npm run build
   ```

## Code Quality Standards
- 100% test passing rate across all test suites.
- Zero linting warnings (`npx oxlint`).
- WCAG 2.1 AA accessibility compliance.
- Complete JSDoc annotations on public functions.
